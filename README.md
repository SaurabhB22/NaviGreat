🧭 Navigreat – Smart Campus Navigation System

Smart. Simple. Seamless Campus Navigation.

Navigreat is a web-based smart campus navigation prototype developed to simplify navigation within university campuses. It provides an interactive digital map that helps students, faculty, visitors, and parents easily locate departments, classrooms, hostels, libraries, administrative offices, and other campus facilities. The project aims to reduce confusion, save time, and improve the overall campus experience through a simple and user-friendly interface.

🚀 Features
Interactive campus map using MapLibre GL JS
Search for important campus locations
Building markers with location details
Modern and responsive user interface
Lightweight frontend built with HTML, CSS, and JavaScript
OpenStreetMap/OpenFreeMap integration
Easy to extend with advanced navigation features

🎯 Problem Statement
Large university campuses are difficult to navigate, causing confusion for students, faculty, and visitors. Existing maps often lack detailed campus-level navigation, making it difficult to locate departments, hostels, libraries, and other facilities efficiently.

💡 Solution
Navigreat provides an interactive campus map that enables users to search, locate, and explore important campus destinations quickly and conveniently. The prototype serves as a foundation for future smart navigation features such as GPS routing, AI assistance, and voice-guided navigation.

🔄 Working Flow
User opens the Navigreat website.
Interactive campus map is displayed.
User searches or selects a destination.
Building information and location are displayed.
(Future) System generates the best navigation route.
User reaches the destination efficiently.
